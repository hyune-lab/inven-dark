# 프로젝트 개요 (Brief)

- 프로젝트: inven-dark
- 작성일: 2026-11-19 / 상태: 초안

## 한 줄 요약
인벤을 오래 보는 PC 사용자를 위해, 인벤에서만 눈부심 없는 다크 모드를 입혀 주는 크롬 확장 프로그램.

## 문제
- 누가: PC로 인벤 게시판을 자주, 오래 보는 사용자
- 어떤 상황에서: 밤이나 어두운 방에서, 또는 다크 모드 환경에서 인벤을 볼 때
- 무엇이 불편한가: 인벤은 다크 모드를 지원하지 않아 하얀 화면이 눈부시고, 오래 보면 눈이 피로하다
- 지금은 어떻게 해결하나(대안):
  - 다크 리더(Dark Reader) 같은 범용 다크 모드 확장 — 사이트를 가리지 않고 색을 자동 계산해서 바꿈. 인벤에서 색이 어색하거나 깨지는 부분이 있을 수 있고, 다른 사이트에도 쓰려면 설정을 따로 해야 함
  - 크롬 자체의 강제 다크 모드 실험 기능 — 모든 사이트에 적용되고 품질이 들쭉날쭉
  - 화면 밝기를 낮추거나 그냥 참고 봄

## 타겟 사용자
- 핵심 사용자: PC 크롬 계열 브라우저(크롬·웨일·엣지)로 게임 인벤 게시판을 매일 보는 사람. 다크 모드 환경을 선호함
- 이 사람이 원하는 결과: 설치만 하면 인벤의 게시판 목록·글·댓글이 어둡고 읽기 편하게 보이고, 다른 사이트는 그대로
- 지금은 타겟이 아닌 사람: 휴대폰으로 인벤을 보는 사람(휴대폰 크롬은 확장 프로그램 불가), 파이어폭스 사용자

## 목적
개인 도구가 기본이다. 여기에 두 가지가 더해진다.
- 포트폴리오: "AI를 활용해 내게 필요한 것을 만들어 보는 취미"의 사례로 소개
- 공유: 만족스러우면 크롬 웹 스토어에 올리고 인벤 커뮤니티에 소개해 다른 사용자도 쓰게 함

## 목표 (성공의 정의)
- 1단계 (나): 2주 안에 내가 매일 켜고 쓰는 수준 — 게시판 목록·글 보기·댓글·상단 메뉴에서 눈에 띄게 깨진 곳이 없고, 다크 리더보다 보기 좋다고 판단
- 2단계 (공유): 1단계 통과 후 크롬 웹 스토어에 공개, 인벤에 소개하고 한 달 안에 설치 50명
- 보조 지표: 웹 스토어 별점과 후기, 깨진 화면 제보 수

## 가치 제안
범용 다크 모드와 달리 인벤 화면에 맞춰 직접 칠했기 때문에 색이 자연스럽고, 인벤 말고 다른 사이트에는 전혀 손대지 않는다.

## 가정과 위험
| 가정 | 틀리면 생기는 일 | 위험도 | 확인 방법 |
|---|---|---|---|
| 인벤 전용 스타일이 다크 리더보다 확실히 보기 좋다 | 만들 이유가 약해지고 공유해도 아무도 안 씀 | 상 | 설계 전 작은 시험: 글 보기 한 화면을 직접 칠해서 다크 리더 적용 화면과 나란히 비교 |
| 인벤 게시판들이 공통 화면 구조를 쓴다 | 게임 게시판마다 따로 칠해야 해서 일이 몇 배로 늘어남 | 상 | 서로 다른 게임 인벤 게시판 3~4곳의 화면 구조 비교 |
| 페이지가 그려지기 전에 어두운 스타일을 넣어 하얀 번쩍임을 막을 수 있다 | 페이지를 열 때마다 하얗게 번쩍여 오히려 눈이 피곤함 | 중 | 작은 시험에서 페이지 이동·새로고침 때 확인 |
| 인벤이 화면을 자주 바꾸지 않는다 | 개편 때마다 깨져서 손봐야 함 | 중 | 운영하면서 깨짐 제보로 확인. 못 칠한 부분은 색 반전으로 보완해 피해를 줄임 |
| 웹 스토어 공개와 이름에 '인벤'을 써도 문제없다 | 심사 거절이나 상표 문제 | 하 | 공개 전에 "인벤용 비공식 도구"로 표기하고 웹 스토어 정책 확인 |

## 열린 질문
- 이름과 아이콘(웹 스토어 공개 시)
- 게시판 외 화면(메인, 뉴스, 마이페이지)을 언제 넓힐지
- 인벤 게임 배너·광고 영역을 어떻게 처리할지(어둡게 / 그대로)

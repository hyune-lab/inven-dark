# 0001. 빌드 도구 없는 순수 JS·CSS 크롬 확장(MV3)으로 만든다

- 날짜: 2026-11-19 / 상태: 채택

## 배경
인벤에서만 다크 모드를 입히는 도구가 필요하다. 다른 사이트에 영향이 없어야 하고, 1인이 가볍게 운영해야 한다.

## 결정
- 크롬 확장 매니페스트 3판, content_scripts 주소 조건을 `*.inven.co.kr`로 한정
- 인벤 전용 CSS를 직접 작성(색 자동 계산·전체 반전 방식이 아님), 못 칠한 영역만 보완 규칙
- React·번들러 없이 순수 JS·CSS. 화면은 아이콘 창 하나뿐이라 공용 기본값(React)의 예외로 둔다

## 대안
- 사용자 스크립트(탬퍼몽키): 설치 문턱이 높아 공유에 불리
- 색 자동 계산(다크 리더 방식): 무겁고, 이미 있는 다크 리더와 차별점이 없음
- React + Vite 확장 템플릿: 아이콘 창 하나에 비해 과함

## 결과
- 압축 해제 폴더를 그대로 크롬에 올려 바로 시험 가능, 웹 스토어 제출도 폴더 압축만 하면 됨
- 인벤 화면 개편 시 CSS를 손봐야 함

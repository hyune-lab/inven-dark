# 기능 정의 (PRD)

- 프로젝트: inven-dark
- 작성일: 2026-11-19 / 상태: 승인됨 (사용자: "계속 진행하고 직접 시험해 볼 수 있는 단계까지 만들어 봐")
- 트랙: MVP

## 사용자 시나리오
1. 사용자가 확장을 설치하고 시스템이 다크 모드인 상태에서 인벤 게시판에 들어간다. 페이지가 하얗게 번쩍이지 않고 처음부터 어둡게 열린다. 목록·글·댓글이 편하게 읽힌다.
2. 낮에 확장 아이콘을 눌러 "끄기"를 고르면 열려 있는 인벤 탭이 새로고침 없이 바로 원래 화면으로 돌아간다. "켜기"를 고르면 시스템 설정과 상관없이 어둡게 보인다.
3. 같은 브라우저로 다른 사이트(예: 네이버)에 가면 아무것도 바뀌지 않는다.

## 기능 목록
| ID | 기능 | 우선순위 | 인수 조건 |
|---|---|---|---|
| F-01 | 인벤에서만 동작 | Must | `*.inven.co.kr`가 아닌 사이트에서는 확장 코드가 실행되지 않는다(설정 파일 기준), 확장 권한은 저장 기능(storage)만 요청한다 |
| F-02 | 게시판 핵심 화면 다크 스타일 | Must | 게임 게시판 목록·글 보기·댓글·상단 메뉴에서 배경이 어둡고 글자가 읽히며, 흰 바탕 덩어리나 읽을 수 없는 글자가 눈에 띄지 않는다. 사진·동영상·이모티콘 색은 바뀌지 않는다 |
| F-03 | 번쩍임 방지 | Must | 다크 상태에서 페이지 이동·새로고침 때 흰 화면이 보이지 않는다 |
| F-04 | 켜기/끄기/자동 | Must | 확장 아이콘 창에서 자동(시스템 따라, 기본값)·켜기·끄기를 고를 수 있고, 고른 값이 저장되며 열린 인벤 탭에 새로고침 없이 바로 반영된다 |
| F-05 | 못 칠한 영역 보완 | Should | 전용 스타일이 없는 인벤 화면(메인·뉴스 등)도 최소한 어둡게 보인다 |
| F-06 | 웹 스토어 공개 준비(이름·아이콘·소개 글) | Could | 2단계 목표 때 |
| — | 휴대폰·파이어폭스 지원, 인벤 외 사이트, 색 테마 고르기 | Won't | 이번 범위 밖 |

## 범위 밖
- 모바일 인벤(m.inven.co.kr), 파이어폭스, 다른 사이트
- 광고·외부 배너 내용 수정
- 서버, 로그인, 사용 통계 수집 — 아무 정보도 밖으로 보내지 않는다

## 비기능 요구
- 성능: 정적 스타일 중심. 페이지 열림이 체감상 느려지지 않을 것
- 개인정보: 수집·전송 없음. 저장하는 값은 모드 설정 하나
- 접근성: 본문 글자와 배경의 명도 대비 4.5:1 이상
- 지원: PC 크롬·웨일·엣지 최신판

## 성공 지표
- 1단계: 사용자가 2주간 매일 사용, 깨진 곳 제보 목록이 줄어듦
- 2단계: 웹 스토어 설치 수
